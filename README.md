# Projeto-Curriculum

criando um modelo de curriculo com html e css, meio que se acostumando a usar diferentes tags e propriedades do css,

sera um projeto estatico, nao precisa de instrucoes para rodar.

para adicionar novas secoes no curriculo voce criar uma tag chamada section embaixo das section ja existentes no html, nao precisa se preocupar em formatacao, pois ja esta inclusa no css, para adicionar uma experiencia nova e so seguir o exemplo do conteudo ja existentes nas sections
por exemplo nas experiencias profissionais se criar uma tag li e depois dentro da tag li cria a tag strong, e so seguir os conteudos ja existentes
pra adicionar uma section nova e so criar no html e citar a class = titulo-secao que a formatacao ja vai ficar bonitinha e encaixada nas divs ja existentes.
